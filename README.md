# 네이버 쿼리 추정기

원하는 키워드를 줄로 구분해 입력하고 선택한 기간의 일별 검색량을 추정하는 도구입니다. 자동 예약 수집 없이 사용자가 검색할 때 추출합니다.

- 브랜드명 옆 **자동** 버튼으로 NAVER 검색광고 API 연관 키워드를 최대 30개 추천받습니다. 추천 목록은 직접 수정하거나 추천 전으로 되돌릴 수 있습니다.
- **일별 흐름**에는 전체 키워드의 일별 추정 쿼리 합계를 굵고 부드러운 한 줄로 표시합니다. 세부 키워드 흐름과 PC/MO 누적 막대도 쿼리 추정량 기준입니다.
- **전체 엑셀** 오른쪽에 같은 스타일의 **기존 분석 불러오기** 버튼을 배치했습니다. 저장한 분석 파일을 업로드하면 쿼리 데이터를 복원합니다.
- 새 추출 전에 기존 결과를 엑셀로 저장하도록 안내합니다. 추출 중에는 반투명 전체 화면에 진행 게이지만 표시하고 배경 조작을 차단합니다. 완료 또는 실패 시 해제되며 실패한 작업은 재시도할 수 있습니다.
- 광고비·유튜브·뉴스 기능은 제거했습니다. 이전 형식의 분석 파일도 쿼리 데이터만 불러옵니다.
- 엑셀의 보이는 시트에는 그룹/키워드/성별/연령/PC/MO/추정 쿼리수(정수) 7개 열만 담습니다. 날짜와 시계열은 숨김 복원 시트에 보관합니다. 성·연령별 절대 건수는 근거가 없어 공란입니다.

## 구성

`docs/`는 GitHub Pages 프런트엔드이며 `docs/config.js`에 공개 서버 주소가 있습니다. `web/`는 원본 UI, `worker/keywords.js`는 연관 키워드 추천, `worker/runtime.js`는 네이버 쿼리 수집과 저장소 API입니다. `node scripts/build-public.mjs`로 Pages 파일을 갱신합니다.

인증키는 서버 환경변수에만 보관합니다. Cloudflare Worker 호환 서버와 `BUCKET` R2 바인딩, 다음 환경변수가 필요합니다: `NAVER_HUB_CLIENT_ID`, `NAVER_HUB_CLIENT_SECRET`, `NAVER_SEARCHAD_LICENSE`, `NAVER_SEARCHAD_SECRET`, `NAVER_SEARCHAD_CUSTOMER`.

트렌드 API 예상 사용량은 `23 × ceil(중복 제외 키워드 수 / 5)`입니다. 추천은 검색광고 API를 사용하며 트렌드 API Budget을 사용하지 않습니다. Budget은 이 사이트가 파악한 호출 시도 기준 추정치입니다.

## 쿼리 추정 방식

일별 추정량 = 월간 PC 검색수 × 해당일 PC 지수 / 기준 30일 PC 지수 합 + 월간 MO 검색수 × 해당일 MO 지수 / 기준 30일 MO 지수 합.

기준 기간은 수집일 전날까지 30일로 가정합니다. PC/MO의 조회 기간과 기준 기간을 같은 요청에 포함하여 지수 스케일을 맞춥니다. 실제 일별 검색 건수가 아닌 고정 보정계수를 적용한 소급 추정입니다. `<10`, 기준 지수 누락 및 0 합계는 추정하지 않습니다.
